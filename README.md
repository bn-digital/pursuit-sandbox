# Consultant Component Sandbox

This is a stripped-down Next.js project to be used as a sandbox for developing and testing React components. It mirrors the production environment's dependencies and folder structure without requiring database or authentication connections.

You can find the template/example component here:

// app/settings/consult/projp/template-project/components/TemplageComponent.tsx

First component to be developed:

// app/settings/consult/projp/actionable-advice-proj/components/ActionableAdvice.tsx

## Getting Started

### 1. Installation

First, install the project dependencies. This will use `package-lock.json` to install the exact versions of all required libraries.

```bash
npm install
```

### 2. Run on local

Second, run on local. The homepage links to template and other components.

```bash
npm run dev
```

Open on your browser: http://localhost:3000/
